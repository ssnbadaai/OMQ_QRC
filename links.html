Sign in

Short links are stored in your GitHub repository, so creating one needs an access token with permission to write to it. The token is saved only in this browser — it is never uploaded to the site or committed to the repo.

How do I get a token?
  1. Open github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Click Generate new token.
  3. Under Repository access, choose Only select repositories and pick OMQ_QRC.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Generate it, copy the token, and paste it above.

Give it an expiry you are comfortable with. When it expires, links keep working — you just need a new token to create or edit them.
