It is not one of ours — what now?

Identifying an arbitrary font from a picture takes a model trained on a large font corpus, which is not something this page can do. Crop tightly to a word on a plain background, then run that crop through a dedicated service such as WhatTheFont or Font Squirrel Matcherator. Once you know it, add it here so nobody has to ask twice.
